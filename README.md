# Nova AI Studio ✨

Nova AI Studio is a next-generation, high-performance web application designed for interactive AI assistance, code generation, and prompt engineering. Built with vanilla HTML5, CSS3 glassmorphism design, and pure JavaScript.

![Nova AI Studio](https://img.shields.io/badge/Nova_AI_Studio-v1.0-6366f1?style=for-the-badge)

## 🌟 Key Features

- **Interactive AI Chat Assistant**: Ultra-fast response streaming simulation with Markdown rendering, inline code highlighting, and 1-click copy.
- **Live HTML/CSS Sandbox Playground**: Split-screen live preview drawer that renders generated HTML and JavaScript components instantly.
- **Prompt Engineering Vault**: Curated library of production-grade prompt templates for UI design, canvas physics, API schemas, and CSS keyframe animations.
- **Studio Theme Customization**: Custom color themes (Electric Indigo/Cyan, Neon Violet/Pink, Emerald Matrix) with temperature and system instruction tuning.
- **State Persistence & Export**: LocalStorage conversation history saving and 1-click HTML project exporting.

## 🚀 Quick Start

### Option 1: Direct Browser Launch
Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server
```bash
npx serve .
# or
python -m http.server 8000
```
